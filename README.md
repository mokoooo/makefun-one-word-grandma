One word a grandma would text about AI. `main.py` writes that single word to `/output/entry.txt` (UTF-8, 1–30 characters) for make.fun's "One Word From Grandma" bounty, judged blind pairwise on funnier + more grandma-like.

## Run it

```sh
python3 main.py
```
